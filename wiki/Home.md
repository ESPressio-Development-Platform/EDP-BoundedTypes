# EDP-BoundedTypes Developer Wiki

EDP-BoundedTypes provides fixed-capacity, allocation-free value and container types with compile-time memory-boundedness certification.

This Wiki is maintained beside the code on `main`. Source code and repository `docs/` remain normative; the Wiki is the internal developer explanation/navigation layer.

## Public entry point

```cpp
#include <ESPressio_BoundedTypes.hpp>
```

## Dependencies

Mandatory: EDP-Memory and EDP-Platform-Portable.
